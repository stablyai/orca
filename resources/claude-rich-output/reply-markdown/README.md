# reply-markdown

Formats terminal replies as headings, lists, callouts, tables, inline spans, and copyable code cards. Code fences remain literal. Bundled by Orca as an optional module derived from NeonCoat by Nate Chia (MIT). Enable Claude Rich Output in Orca Terminal settings and start a new Claude session. Existing sessions and global Claude settings are not changed. Compatible experimental Claude function hooks are required. See the parent README for compatibility, limits, and provenance.

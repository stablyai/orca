# 真机验证

本清单用于 API 26 / HarmonyOS 7 调试包。构建通过和模拟器通过不代表以下真机项目已通过。此文档不预填“已验证”。

## 安装前

- [ ] 确认设备 API 26，DevEco 的签名 profile 包含这台设备，bundle ID 与 profile 一致。
- [ ] 运行 `node tools/check.mjs`、`bash tools/build.sh --clean --require-signed` 和 `bash tools/verify-hap.sh`。
- [ ] 保存 `dist/build-report.json` 与 HAP 的 SHA256；记录设备型号、系统版本、桌面 Orca 版本。
- [ ] 手机与桌面在可互通的网络。真机使用桌面局域网地址；`10.0.2.2` 只适用于模拟器。
- [ ] 在 DevEco Studio 选择目标手机运行，或明确指定 `hdc -t <device-id> install -r <signed.hap>`，不要在同时连接手机和模拟器时省略设备 ID。

## 新增对齐验收

- [ ] 在首次连接页检查 Orca 标志、三步指引及「配对桌面」入口。从扫码和粘贴分别配对，再通过外部链接核对确认和取消。撤销相机权限后，粘贴失败仍应显示指引与重试。完成会话界面和在线通知两步后应进入桌面，已保存的选择应跳过。
- [ ] 首次引导进入在线通知页时，示例卡片依次出现并一起淡出，正文和按钮保持原位。启用系统「减弱动效」后，两张卡片静态显示，引导切换不滑动。切到后台再返回，核对通知选择仍可完成。
- [ ] 在横屏或较矮的应用窗口里连接无法应答的测试桌面。检查失败日志能滚动，仍可到达「重试」和「改为粘贴配对码」。返回扫码后相机应重新启动。关闭粘贴抽屉、前后台切换和退出扫码时核对相机释放与恢复。
- [ ] 同时连接两台桌面，单独断开、重新连接、编辑和移除其中一台。网络诊断切换桌面后只显示所选桌面的记录，复制报告时不会带入凭证或其他桌面的事件。
- [ ] 检查已连接桌面的卡片是否显示桌面报告的机型和系统，以及该桌面待处理的智能体数量。点按进入工作区列表，返回动态后长按同一张卡片打开桌面操作。打开任务时只选择已连接的桌面。
- [ ] 在收到桌面的机型信息后断开测试链路，终止并重开应用。核对桌面卡片仍显示机型、系统与自定义名称。打开缓存工作区，表头显示连接状态且创建操作不可用。恢复链路后，原页面应显示机型与系统并恢复实时操作。

- [ ] 从已连接的桌面打开终端设置，返回后进入工作区，再打开该桌面的网络诊断。核对页面切换期间没有新增认证记录。支持预渲染的设备应出现「会话页面已预热」和「已复用预热页面」两条记录。进入后台或触发内存回收后，再验证工作区能冷启动。
- [ ] 在线打开测试桌面的工作区列表，返回首页后断开测试链路并重启应用。打开该桌面时，已有缓存的工作区仍可查看，实时操作保持禁用。恢复链路后，验证同一页面恢复交互。更换桌面页面包时核对原页面保持可用，新包在下次进入时才启用。让测试桌面拒绝下载，再用可下载但无法首帧的测试包，分别验证保留当前页、回退旧版和关闭提示。再次配对或移除桌面后，旧的配对缓存不能用于离线打开。
- [ ] 让隔离桌面分别缺少页面包、提供低于要求的页面版本、要求新版手机或给某个路由声明未知必需权限。核对更新或刷新页面的提示与返回入口，确认工作区内容未加载。用宽屏独占的旧版清单在手机上打开会话并返回工作区列表。
- [ ] 在隔离的测试终端打开和关闭软键盘。键栏及输入框随键盘避让，桌面 PTY 的行列数保持稳定。通过键栏发送 Tab、Enter、Esc 并确认字节。中断和恢复连接时，工作区保留终端画布，由网页显示连接状态。
- [ ] 在普通屏幕纵屏和横屏打开同一个测试终端。通过底部键栏点按和按住方向键，核对桌面收到的控制序列和松手后的停止。折叠屏另外核对折痕两侧的列表与工作区，移动应用窗口后检查分栏是否及时恢复。
- [ ] 在系统提供可绘制侧边区域的设备上打开终端，核对键栏与底部键栏的交接、方向键盘开关、键盘遮挡和软键盘开合。按住方向键时切换窗格、离开会话或断开桌面，核对旧按键不会发给其他窗格，也不会在重连后补发。
- [ ] 断开局域网后通过官方 Relay 恢复，回到局域网后升级直连；移动网络、凭证轮换和桌面重启均可恢复。
- [ ] 用隔离桌面通过 Relay 配对。分别在凭证安装已提交、续租确认已提交而手机尚未保存时终止应用。重开后应恢复同一桌面并能打开工作区。临时断网时已有桌面仍可见，移除桌面后旧配对记录不可恢复它。
- [ ] 使用情况显示真实 stats/quota；重置额度先显示准确账户/WSL确认，取消不执行，重复点击不重复消费。
- [ ] 自动化开关核对 owner 与最近运行；新建、管理和运行打开真实共享页面。
- [ ] 使用情况和自动化分别选择两台桌面。切页、取消选择、断开其中一台后，已选桌面保持稳定。刷新只请求使用情况页所选桌面，自动化启停和新建只作用于自动化页所选桌面。
- [ ] 在首页点「＋」新建工作区。只连一台桌面时直接展开表单，两台在线时先选桌面。取消选择、关闭表单或返回都应留在首页。用隔离 Git 仓库创建后进入所选桌面的会话，再返回首页。
- [ ] 在隔离 Git 仓库中选择空白终端，输入独立的工作区名称和带斜杠的分支名。创建后在桌面核对实际 Git 分支与手动输入一致。
- [ ] 在两台隔离桌面的测试会话里产生智能体事件。核对动态页逐条更新，以及智能体页的桌面筛选、搜索和长按菜单。标为已读、标为未读并清除已完成项后，核对各自桌面的活动状态。点按行应打开该桌面的指定窗格。
- [ ] 让同一桌面的本机和 SSH 工作区使用相同的原始 ID。核对列表分组仍独立。若桌面会话清单只能按原始 ID 定位，核对手机提示歧义并留在当前页。
- [ ] 远程 folder 工作区、指定 pane 的通知/深链接，冷启动和重连后仍定位正确。
- [ ] 在应用打开和退出后分别打开已配对桌面的会话链接。系统返回或表头返回先回到同一桌面的工作区列表，再回首页。新版桌面同时验证页面更新后不会重复打开同一会话。
- [ ] 向隔离桌面发送在线提醒并点系统通知，核对打开的是指定 pane。关闭总开关、开启免打扰或查看同一工作区时，核对系统栏没有相应提醒。
- [ ] 进入测试会话，分别用系统返回、边缘手势和网页返回回到工作区列表。让测试网页重复发送返回通知，确认只退一层。打开网络诊断后从旧网页发送迟到的返回通知，诊断应保持打开。
- [ ] 让通知留在系统栏，断开连接，在桌面撤回后恢复连接。核对旧提醒消失且没有补发，同一 ID 的新提醒仍可显示。升级前已存在的通知没有供此检查使用的桌面回执。
- [ ] 浏览器 screencast 可见、点击可用；大 diff/列表没有因帧上限永久等待。
- [ ] PDF/图片复制保存分享真实成功；预览或下载时离开页面不会打开旧结果。
- [ ] 无桌面时检查转写位置与本机状态。连接隔离桌面后切换听写开关和模式，下载、选用并删除本地模型。断线时模型操作不可用，恢复连接后重新读取桌面状态。检查未配置 OpenAI 密钥的模型状态。
- [ ] 语音分别验证 Computer / Automatic / This phone，普通话离线服务、非中文fallback、电话中断及待授权时进入后台。
- [ ] 原生设置和共享网页内调整互相同步，杀进程重开后仍保存；清理主机只清理该主机数据。

## 记录失败

记录上述构建指纹、最短复现步骤、期望与实际结果、前后台和网络状态、权限选择、经过脱敏的日志及截图。不要附带配对二维码、token、签名文件或完整设备 profile。终端测试使用单独测试会话，避免把剪贴板中的未知命令送进真实工作终端。

已知范围：最低 API 26；直连与Relay均已实现但需真实链路验收；端上识别由系统提供离线普通话。Orca 官方网关尚无 HarmonyOS Push 通道，应用退出后的远程推送受此限制。此调试包不代表 AppGallery 发布包。

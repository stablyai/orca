# 真机验证

本清单用于 API 26 / HarmonyOS 7 调试包。构建通过和模拟器通过不代表以下真机项目已通过。此文档不预填“已验证”。

## 安装前

- [ ] 确认设备 API 26，DevEco 的签名 profile 包含这台设备，bundle ID 与 profile 一致。
- [ ] 运行 `node tools/check.mjs`、`bash tools/build.sh --clean --require-signed` 和 `bash tools/verify-hap.sh`。
- [ ] 保存 `dist/build-report.json` 与 HAP 的 SHA256；记录设备型号、系统版本、桌面 Orca 版本。
- [ ] 手机与桌面在可互通的网络。真机使用桌面局域网地址；`10.0.2.2` 只适用于模拟器。
- [ ] 在 DevEco Studio 选择目标手机运行，或明确指定 `hdc -t <device-id> install -r <signed.hap>`，不要在同时连接手机和模拟器时省略设备 ID。

## 记录失败

记录上述构建指纹、最短复现步骤、期望与实际结果、前后台和网络状态、权限选择、经过脱敏的日志及截图。不要附带配对二维码、token、签名文件或完整设备 profile。终端测试使用单独测试会话，避免把剪贴板中的未知命令送进真实工作终端。

已知范围：最低 API 26；直连；无 Huawei 远程 Push、screencast、端上识别和无衬线终端字体。此调试包不代表 AppGallery 发布包。

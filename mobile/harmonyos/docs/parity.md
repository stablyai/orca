# iOS alignment and verification

The reference is the iOS client at stablyai/orca commit `10c01509de6769f5a8baef080c993d77ac493127`, together with its desktop mobile-web bundle and shared RPC contracts. HarmonyOS uses system camera, permission, photo, share and PDF interfaces for the corresponding iOS flows.

## Interpretation

The generated Home presentation adapter reuses Orca's shared automation schedule descriptor, terminal agent names and quota reset countdown. The HarmonyOS adapter supplies the same UTF-8 length check through ArkTS encoding.

Use the [device checklist](device-testing.md) for device acceptance. A physical API 26 phone paired to an isolated Orca 1.4.251 runtime, opened a folder workspace and terminal, sent an ASCII command, and recovered after the USB forwarding rule was restored. A separate run opened terminal settings, the workspace page and network diagnostics without adding a desktop authentication event. Diagnostics also recorded successful reuse of the pre-rendered document. The official Relay and device-specific flows in the checklist require separate runs. Fixed E2EE vectors exercise the actual cryptographic code.

The Agents list keeps local and SSH workspaces separate when their raw workspace IDs collide. The shared desktop session inventory and terminal subscriptions still key sessions by the raw workspace ID, so ambiguous rows stay visible and block pane navigation. Delegated runtimes require a separate capability for activity writes.

The official gateway limitation prevents terminated-app notification parity. The maintainer-owned AppGallery Connect project, app identity, signing and Huawei Push Kit credentials belong to the production release. The local debug package uses the contributor's development bundle ID and supports online notifications.

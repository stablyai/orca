## Interpretation

Use the [device checklist](device-testing.md) for device acceptance. A physical API 26 phone paired to an isolated Orca 1.4.251 runtime, opened a folder workspace and terminal, sent an ASCII command, and recovered after the USB forwarding rule was restored. The official Relay and device-specific flows in the checklist require separate runs. Fixed E2EE vectors exercise the actual cryptographic code.

The official gateway limitation prevents terminated-app notification parity. The maintainer-owned AppGallery Connect project, app identity, signing and Huawei Push Kit credentials belong to the production release. The local debug package uses the contributor's development bundle ID and supports online notifications.

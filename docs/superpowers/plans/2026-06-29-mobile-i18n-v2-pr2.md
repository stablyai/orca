## Phase 7: Clean up v1 leftovers

### Task 21: Fix the 3 `*-styles.ts` expo-router warnings

The v1 split left `accounts-screen-styles.ts`, `mobile-session-{command-input,frame,styles}.ts` in `app/h/[hostId]/`. Expo-router's file-based routing thinks they're routes. Fix:
- Either rename with a leading underscore: `_session-styles.ts` (convention for non-routes)
- Or move them out of `app/` to a sibling folder like `app/h/[hostId]/_styles/`
- Or update the `.gitignore` of expo-router config

The simplest fix: rename with leading underscore.

```bash
git add mobile/app/h/\[hostId\]/accounts-screen-styles.ts mobile/app/h/\[hostId\]/session/mobile-session-{command-input,frame,styles}.ts
# Then update the import paths in the corresponding *.tsx files
git commit -m "refactor(mobile): rename *-styles.ts with leading underscore to suppress expo-router warnings"
```

---
title: Work on a remote machine over SSH
---

Point Orca at any SSH target — a beefier dev box, a GPU host, a cloud sandbox — and it feels like a local worktree. Same editor, same diff view, same agents, different compute. You can open remote repos _or_ just arbitrary folders. For the full menu of local / SSH / server / ephemeral-VM modes, see [Ways to run Orca](/docs/ways-to-run).

## Setup

1. Add the host under [Settings → SSH](/docs/settings).
1. Test the connection. Make sure git is installed on the host if you're working with a repo.
1. Add the repo to Orca, selecting the SSH target as its location — or open any remote folder directly from the file picker.

## Run

1. Create a worktree. Orca runs `git worktree add` on the remote.
1. Launch an agent — it runs on the remote host, not your laptop.
1. Edit files inline — Orca streams saves to the remote filesystem.
1. Review the diff, commit, and push from your laptop as usual.

## Disconnects

Laptop sleeps, Wi-Fi drops — the agent keeps running remotely. Orca reconnects and re-attaches the terminal. Nothing lost.

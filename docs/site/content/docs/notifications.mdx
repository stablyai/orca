title: Notifications & Inbox
---

Orca runs agents, not just terminals, so it knows when an agent actually finishes versus when it's just paused. Notifications lean on that signal so you can queue three agents, walk away, and come back when the first one is done.

## Agent-finished pings

When an agent transitions from working to idle, Orca fires a notification — system notification, sound, and a chip on the worktree.

## User action or whole flow complete

Under **Settings → Notifications**, keep **Agent Task Complete** enabled and select
**User action or whole flow complete** in **Agent notification mode**. The default,
**Current behavior**, preserves existing alerts.

For Claude and Codex, the opt-in mode sends an alert for an unresolved question or
approval, a blocking failure, or successful completion after all tracked work has
settled and stayed quiet for 1.5 seconds. Tool activity and parent turn endings
while background commands run stay quiet. Claude and Codex terminal bells are
also silent in this mode. Other providers keep their existing behavior.

For example, if a parent finishes its response while a background build runs,
current behavior can alert at the response ending. Whole-flow mode keeps completion
pending through the build and any continuation it triggers, then alerts once the
flow settles. A server or monitoring command keeps completion pending until it
finishes or is stopped.

The mode applies before desktop and phone delivery. Existing sound, volume, focus,
phone, machine, and hidden-workspace preferences still apply. Ordinary unread
markers and notification history continue to follow turn events.

Remote execution hosts save their own mode for phone delivery. Their controls
appear beneath the local mode in Notifications settings. Older hosts retain
current behavior and show **Update this host to use whole-flow notifications**.
Unknown lifecycle evidence is never treated as successful completion.

## Persistent bell

The header bell shows unread notifications across all worktrees. Clicking a notification jumps to the matching worktree and pane.

On macOS, the same unread count is mirrored as a badge on the Dock icon, so you can spot pending agent pings without bringing Orca to the foreground.

## Mark unread

Right-click a notification to mark unread — useful when you've triaged something but want to come back to it later.

## Tuning

Turn off specific categories (system, sound, chip-only) under [Settings → Notifications](/docs/settings).

## Custom sounds

Pick a custom desktop notification sound per category under [Settings → Notifications](/docs/settings) — point at any audio file on disk, or pick from Orca's built-in set. Useful when you want agent-finished pings to stand out from system mail and Slack.

Supported formats: MP3, WAV, OGG, M4A, AAC, FLAC. One file applies to all delivered desktop notifications.

When you use a custom sound, set its playback volume from the same settings pane.

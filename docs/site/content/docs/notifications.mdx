---
title: Notifications & Inbox
---

Orca runs agents, not just terminals, so it knows when an agent actually finishes versus when it's just paused. Notifications lean on that signal so you can queue three agents, walk away, and come back when the first one is done.

## Agent-finished pings

When an agent transitions from working to idle, Orca fires a notification — system notification, sound, and a chip on the worktree.

## Persistent bell

The header bell shows unread notifications across all worktrees. Clicking a notification jumps to the matching worktree and pane.

On macOS, the same unread count is mirrored as a badge on the Dock icon, so you can spot pending agent pings without bringing Orca to the foreground.

## Jump to the latest input request

Press `Cmd+Shift+U` on macOS or `Ctrl+Shift+U` on Windows/Linux to open the newest agent
still waiting for input or blocked on a request, including its tab and split pane. Remap
**Jump to latest agent needing input** in Settings → Shortcuts.

The action uses fresh agent status, rather than older notifications or completed turns.
Reading a request does not resolve it: repeated presses return to the same newest pending
request until the agent resumes or another request arrives. When nothing needs input,
the shortcut passes through to the focused terminal. It also works with folder workspaces,
floating terminals, structured chats, and SSH/remote workspaces.

## Mark unread

Right-click a notification to mark unread — useful when you've triaged something but want to come back to it later.

## Tuning

Turn off specific categories (system, sound, chip-only) under [Settings → Notifications](/docs/settings).

## Custom sounds

Pick a custom desktop notification sound per category under [Settings → Notifications](/docs/settings) — point at any audio file on disk, or pick from Orca's built-in set. Useful when you want agent-finished pings to stand out from system mail and Slack.

Supported formats: MP3, WAV, OGG, M4A, AAC, FLAC. One file applies to all delivered desktop notifications.

When you use a custom sound, set its playback volume from the same settings pane.

# Root Dependency Audit

Scope: root `package.json` direct `dependencies`, `devDependencies`, and `optionalDependencies`.

Result: direct dependency entries were reduced from 113 to 108. This first pass removes the small Markdown/git helpers that were easy to replace locally while keeping popular/tooling packages for a lower-risk initial change.

## Removed Direct Dependencies

| Package                | Result               | Rationale                                                                                                                                                                                                  |
| ---------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `entities`             | Removed direct entry | Replaced with a scoped local fork of the small `entities@6.0.1` surface used for TOC label cleanup.                                                                                                        |
| `github-slugger`       | Removed direct entry | Replaced with `MarkdownHeadingSlugger`, a scoped local fork of the heading slug behavior from `github-slugger@2.0.0`. Removed from lockfile entirely.                                                      |
| `hosted-git-info`      | Removed direct entry | Replaced with `buildHostedRemoteFileUrl`, a scoped local fork of the `hosted-git-info@9.0.3` remote parsing/file URL surface Orca used. `hosted-git-info@4` remains transitive through `electron-builder`. |
| `mdast-util-to-string` | Removed direct entry | Replaced with local Markdown AST text extraction, a scoped fork of the heading-node behavior Orca used from `mdast-util-to-string@4.0.0`. It remains only transitively through remark packages.            |
| `rehype-slug`          | Removed direct entry | Markdown heading components already assign ids via the scoped `github-slugger@2.0.0`-compatible local fork, so the `rehype-slug@6.0.0` plugin was redundant. Removed from lockfile entirely.               |

## Transitive Notes

These names still appear in `pnpm-lock.yaml` only because retained packages depend on them:

- `entities`: required by retained HTML/Markdown parsing packages.
- `hosted-git-info@4.1.0`: required by retained `electron-builder`.
- `mdast-util-to-string`: required by retained remark packages.

These removed packages no longer appear in the lockfile at all: `github-slugger`, `rehype-slug`.

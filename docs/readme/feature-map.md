# Feature Map

## Orca Bots

| Flow                        | Entry point                                          | Implementation and data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Open a bot or group         | Desktop sidebar → Bots → row                         | [`SidebarBotsSection`](../../src/renderer/src/components/bots/SidebarBotsSection.tsx) renders bot and group rows from their home workspaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Pin or unpin a bot or group | Desktop sidebar → right-click its row → Pin or Unpin | [`BotSidebarRow`](../../src/renderer/src/components/bots/BotSidebarRow.tsx) updates the home workspace through [`createUpdateWorktreeMeta`](../../src/renderer/src/store/slices/worktrees/metadata/update-worktree-meta.ts). [`FolderWorkspace.isPinned`](../../src/shared/folder-workspaces/folder-workspace-types.ts) stores the preference on the owning host.                                                                                                                                                                                                                                                 |
| List pinned rows first      | Desktop Bots sidebar and paired mobile Bots list     | [`useBotSidebarArrangement`](../../src/renderer/src/components/bots/use-bot-sidebar-arrangement.ts) and [`drawHostBotEntries`](../../mobile/src/bots/host-bot-entries.ts) feed the shared [`arrangeBotSidebarEntries`](../../src/shared/bots/bot-sidebar-view.ts) ordering. [`BotSidebarRows`](../../src/renderer/src/components/bots/BotSidebarRows.tsx) renders pinned entries in a two-column section with 42 px avatars. Expanded chats and workspaces use the sidebar’s full width. The offline desktop list reads the flag from [`kept home snapshots`](../../src/renderer/src/lib/bot-host-kept-homes.ts). |

Run `pnpm check:changed --maxWorkers=2` for the change gate. In an isolated desktop dev profile, pin three lower rows and verify two columns, the larger avatars, and no duplicate rows. Open a pinned bot’s children, reveal a pinned bot in the second column from search, restart the profile, and unpin a row. Use Manual and Agent Activity sorting. Verify that a paired mobile list puts pinned rows first and that a disconnected host keeps its last known pinned order on desktop.

In the desktop fixture, reject one pin and one unpin write. Verify that the row stays in its current section, the save error appears, and each action succeeds on retry.

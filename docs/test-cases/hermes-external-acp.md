# Hermes 외부 ACP 채팅 시험

근거: 신뢰한 외부 Hermes ACP 실행기를 Orca 기본 채팅에 등록하고 로컬·원격에서 같은 대화를 재개한다. 기존 터미널, 내장 에이전트와 사용자 대화를 보존한다.

| 케이스    | 준비 데이터                                          | 실제 입구와 입력                   | 기대 결과                                                     |
| --------- | ---------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| 등록      | 사용자 소유 비공개 JSON과 ACP 실행기                 | 앱 시작, 새 채팅 에이전트 선택     | Hermes가 채팅으로 열리고 내장 에이전트 유지                   |
| 거절      | 중복 ID, 내장 ACP ID 충돌, 상대 경로, 공개 쓰기 권한 | 등록 파일을 읽는 앱 시작           | 외부 실행 거절, 원문·자격 정보 로그 없음                      |
| 로컬 대화 | 로컬 저장소와 고유 시험 식별자                       | Hermes 기본 채팅에 한 줄 응답 요청 | 응답 한 번 표시, ACP 세션 ID 보존                             |
| 로컬 재개 | 완료된 로컬 채팅                                     | 앱 재시작 후 같은 채팅에 후속 요청 | 이전 메시지 유지, 동일 ACP 세션 재개                          |
| 원격 대화 | 등록을 제공하는 원격 서버의 저장소                   | 원격 기본 채팅에서 한 줄 응답 요청 | 호스트가 제공하는 ACP로 실행, 로컬 터미널로 우회 없음         |
| 원격 재개 | 완료된 원격 채팅                                     | 앱 재시작 후 같은 채팅에 후속 요청 | 원격 세션 ID·과거 메시지 유지, 중복 응답 없음                 |
| 모델 표시 | 모델·모드 정보를 제공하는 실제 ACP 서버              | 채팅 응답과 모델 선택 UI 조회      | 서버가 제공하는 모델만 표시, 미제공 실제 모델을 추측하지 않음 |
| 등록 변경 | 명령 또는 인자가 다른 등록                           | 기존 대화 재개                     | 다른 연결에 기존 세션을 조용히 연결하지 않음                  |
| 취소      | 진행 중인 격리 시험 채팅                             | 중지 버튼                          | 해당 턴만 중지, 다른 채팅 영향 없음                           |

| 서버 시험 격리 | 임시 사용자 홈과 실제 sidecar fixture | `pnpm test src/main/orcad/electron-serve-browser-process.test.ts --maxWorkers=1` | 소유권 전달 시험을 포함한 22개 통과, 실제 사용자 홈 쓰기 없음 |

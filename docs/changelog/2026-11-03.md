## 开发变更

### macOS 支持代码与文本文件的打开方式

规格与设计以 [OpenSpec change](../../openspec/changes/add-macos-code-file-open-with/proposal.md) 为准。实现位于独立 worktree `ytr/macos-open-with-code`，基线为 `2169b791b70ae5652c978f0f28068ab266f030b1`。Kaneo 绑定按用户本轮明确授权暂缓。

已复用语言后缀数据，为 macOS 打包声明 253 个 Editor/Alternate 后缀；显式打开的本地普通文件沿用浮动工作区、语言识别和原路径保存。完整 argv 单独跳过程序入口，纯文件路径保留首项。Windows/Linux 的文档接收和安装声明保持原有范围。仓库根目录门禁增加用户已授权初始化的 `openspec`，既有 docs 白名单增加持久化变更记录目录 `docs/changelog`。

隐藏 Electron 测试还复现了冷启动读取被丢弃的问题：浮动工作区目录由 null 初始化为 home 时，通用目录变更保护使已成功的绝对路径读取失效。修复仅排除浮动工作区的目录校验；文件身份、主机归属和项目目录校验仍保留。

所有测试与应用均设置 `ORCA_BACKGROUND_LAUNCH=1`，使用隔离合成文件和用户数据。Node 使用仓库要求的 24，pnpm 使用锁定版本 12.14.0。
